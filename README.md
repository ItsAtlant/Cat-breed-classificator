# Cat Breed Classificator 🐈

An experimental **Computer Vision / Machine Learning** project built while I was learning Python and AI.

The repository explores different approaches for detecting cats, preparing image datasets and experimenting with breed classification.

## Technologies

- Python
- YOLOv8 / Ultralytics
- TensorFlow / Keras
- OpenCV
- NumPy
- Pillow

## Project structure

### `cat-detection-YOLO`
Uses a pretrained YOLOv8 model to detect cats in images and generate bounding-box coordinates that can be used as labels for a dataset.

### `cat-segmentation-YOLO`
Additional experiments with YOLO-based image processing and coordinate generation.

### `neural-network`
Contains a TensorFlow/Keras convolutional neural network experiment for:

- breed classification
- bounding-box prediction
- custom image loading and preprocessing
- model training and prediction visualization

## Status

This is an **older learning project** and is no longer actively maintained. I keep it on GitHub as part of my AI/ML learning path and portfolio.
